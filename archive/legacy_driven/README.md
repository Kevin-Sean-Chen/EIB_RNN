# Legacy driven experiments

These files mixed sine, one-dot, and two-dot experiments in one workflow. Some metrics used a stimulus that the script had already replaced.

Use these current entry points:

- `scripts/driven/run_driven_dot.py` for one moving-dot simulation.
- `scripts/driven/scan_driven_dot.py` for moving-dot tracking across `K`.

The shared stimulus and simulation functions are in `src/`.
