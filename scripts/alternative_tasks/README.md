# Alternative tasks

These scripts preserve secondary task experiments. They are not part of the main scientific workflow.

- `relu2D_ds.py`: direction classification from a drifting sine input.
- `relu2D_res_local.py`: masked-input and local-readout reconstruction.
- `scan_res_memory.py`: delayed reconstruction across delay values.
- `relu2D_force.py`: exploratory driven readout and feedback experiment.

The main tasks are dot prediction, same-time rigid-shift reconstruction, and cue-based working memory.
